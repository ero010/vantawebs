How powerful is it?

Images

Pixel re-render via canvas. Destroys all EXIF / XMP / IPTC / GPS / thumbnail / comment chunks. No copy-paste of metadata possible.

PDF

Rebuilds document, wipes Author / Creator / Producer / dates / XMP / custom keys.

Video & Audio

FFmpeg -map_metadata -1 with stream-copy. Strips title, encoder, GPS, creation_time with zero quality loss and full re-mux.

Honest limit: this removes technical metadata for privacy. It does not remove invisible pixel/audio watermarks (e.g. SynthID) and is not a substitute for legally required AI-content disclosure where applicable (EU AI Act, TikTok / Instagram / YouTube policies).
