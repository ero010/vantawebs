Remove Midjourney Metadata Before Selling Art

Midjourney embeds generation parameters in PNG files. When you generate an image with Midjourney, it stores your prompt, seed number, model version, and other parameters as tEXt chunks in the PNG metadata. If you are selling AI art, this means your buyers could extract your exact prompt and settings or use them to verify the image was AI-generated.

Midjourney images may also contain C2PA Content Credentials or other AI provenance markers that standard metadata tools do not remove. These markers can definitively prove an image was generated by AI, which may affect how buyers value your work or how platforms categorize it.

How to see what is hidden in your file. The quickest way is to drop the PNG into the checker below and read the preview — prompts often appear as plain-text entries. On Windows, right-click the file, choose Properties → Details to see basic tags. On Mac, open it in Preview and press Cmd+I for EXIF and PNG text chunks. For the full picture, a free EXIF viewer will show tEXt, iTXt, and zTXt chunks where Midjourney stores parameters. If you see fields with job IDs, seeds, or version flags, that is what a buyer would see too.

Step-by-step: clean Midjourney files before selling. First, upscale and finalise the image in Midjourney before you clean it — cleaning first and editing later can reintroduce metadata. Second, download the final PNG and keep one untouched original in a private archive folder. Third, drop a copy into the tool below and download the clean version. Fourth, verify the clean copy by checking it again — no prompt, seed, or C2PA entry should appear. Fifth, deliver only the clean copy to Etsy, Gumroad, stock sites, or clients. Use the same clean file for mockups and previews so a sample image does not leak the prompt for the full product.

What gets stripped vs what survives. A proper cleaner removes PNG tEXt/iTXt chunks with prompts and parameters, EXIF and XMP blocks, embedded thumbnails, timestamps, software strings, and C2PA/JUMBF provenance where present. What survives is the artwork itself — pixels, resolution, colour profile appearance, and transparency stay intact. What does not survive is the verifiable link back to the prompt: once the text chunks are gone, the file alone no longer reveals your wording, seed, or settings.

Common mistakes sellers make. The most common is cleaning the final JPG but uploading the original PNG as a bonus file or preview — the prompt leaks through the extra file. Another is screenshotting the image to strip data and then selling the screenshot at lower quality. A third is re-saving the cleaned file in Photoshop with metadata or Content Credentials turned back on, which writes fresh history into a file you just cleaned. Finally, remember that filenames and folder names can leak too: a file called purple-castle-v6-seed-1234 tells its own story even when the inside is clean.

What about upscalers and print shops?

If you run a Midjourney image through an upscaler, Magnific, Topaz, or a print-on-demand service, that service may add its own software tags or C2PA entries. Clean the file after the last processing step, not before. Keep the pre-clean original for your records, and send the post-clean file to the printer or marketplace.

Frequently asked questions

Does converting PNG to JPG remove Midjourney metadata?
Not reliably. Many converters copy text chunks and EXIF into the new file, and some add their own software tags. Convert first if you need a JPG, then strip the converted file so you know the delivered copy is clean.

Will buyers know my art is AI-generated after I strip metadata?
They will not be able to prove it from the file alone, but they may still recognise the style or ask directly. Stripping metadata protects your prompts and delivers professional files, but it does not change marketplace rules — if a site asks whether work is AI-generated, answer honestly.

Should I keep a copy with the prompt for myself?
Yes. Save one original with the full parameters in a private folder so you can reproduce the style, prove creation order, or revisit settings later. Share only clean copies publicly.
